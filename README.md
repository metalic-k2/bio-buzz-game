# 🐝 Bio Buzz — FTC Team SPARK #37729

**An Interactive Biodiversity Game Inspired by the FIRST Canopy Season 2026–2027**

Welcome to **Bio Buzz**, an interactive HTML game developed by **FTC Team SPARK (Team Number: 37729)**. This project combines gaming, creativity, technology, and environmental awareness to encourage students to explore biodiversity and understand the importance of protecting our ecosystems.

## 🌱 About the Project

Bio Buzz is a browser-based game inspired by the themes of biodiversity, ecosystems, and environmental conservation.

Through interactive gameplay, players can explore nature-inspired challenges while learning about the relationships between living organisms and their environments.

This project reflects Team SPARK's commitment to STEM education, innovation, and hands-on learning.

## 🎮 Play the Game

**Play Bio Buzz online:**
https://metalic-k2.github.io/bio-buzz-game/

Open the link in a modern web browser to experience the game.
